# Security policy

## Reporting a problem

If you find a security problem, for example a way the skill could make Claude
send or post a message, copy message text into Notion, write outside its
working folder, get around a macOS privacy prompt, or follow instructions
hidden in a message or email, please report it privately rather than in a
public issue:

- **Preferred:** use GitHub's private
  [Report a vulnerability](https://github.com/phillippmueller/network-sync/security/advisories/new)
  form.
- **Or email:** [philip.mueller.bueckeburg@gmail.com](mailto:philip.mueller.bueckeburg@gmail.com) with "Security" in the subject.

Please include what you asked Claude, what happened, and the plugin version.
Never include real messages or contact details. You'll get a first reply
within 7 days.

## Supported versions

Only the latest release receives fixes.
